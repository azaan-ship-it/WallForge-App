First public release of WallForge.

* 19 real-time live wallpapers across Hacker, Weather, Cars, Space and Cyberpunk.
* Import your own videos, images, GIFs and HTML pages.
* Per-wallpaper speed, intensity, tint, quality and FPS settings; a different wallpaper per monitor; playlist mode; optional ambient sound.
* Auto-pause for fullscreen apps and games, battery saving, and a one-click lock screen.

**Install:** download `WallForgeSetup.exe` below and run it. If SmartScreen appears, click **More info → Run anyway**.
